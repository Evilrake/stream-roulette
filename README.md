# Стрим-рулетка

Десктопное приложение для стрима: рулетка по донатам с порогом, категориями карточек (как в Donation Alerts), звуком и оверлеем для OBS.

**Версия:** 1.2.1  
**Установщик Windows:** [StreamRoulette-Setup-1.2.1.exe](https://github.com/Evilrake/stream-roulette/releases/latest) (вкладка [Releases](https://github.com/Evilrake/stream-roulette/releases))

---

## 1. Установка

1. Скачай `StreamRoulette-Setup-1.2.1.exe` из последнего релиза.
2. Запусти установщик → выбери папку → Далее.
3. Открой **«Стрим-рулетка»** с рабочего стола или из меню «Пуск».

Настройки, задания и ключи платформ сохраняются в профиле Windows (AppData). При обновлении обычно не сбрасываются.

---

## 2. Быстрый старт перед стримом

1. Запусти приложение — откроется панель управления.
2. В **«Задания»** настрой категории и карточки.
3. В **«Экономика»** задай порог, шаг и тайминги → **«Сохранить настройки»**.
4. Подключи платформу донатов через **бургер-меню** в шапке.
5. Добавь источники в OBS.
6. В **«Тест перед стримом»** проверь кнопками `+50` / `+100` / **«Ручная крутка»**.

Индикатор **WS: ok** в шапке — связь панели с локальным сервером приложения. Это не статус Donation Alerts / DonatePay / DonateX.

---

## 3. OBS

Приложение должно быть запущено.

Рекомендуется **два** источника Browser Source:

| Источник | URL | Размер |
|----------|-----|--------|
| Рулетка | `http://127.0.0.1:3847/overlay/roulette/` | ≈ 960 × 540 |
| Порог | `http://127.0.0.1:3847/overlay/hud/` | ≈ 560 × 420 |

Ссылки и кнопки предпросмотра — в блоке **«Ссылки для OBS»**. Фон источника оставь прозрачным.

Альтернативы:

- один общий URL: `http://127.0.0.1:3847/overlay/`
- **Захват окна** → «Оверлей — рулетка» / «Оверлей — порог» (кнопки в панели или `Ctrl+O` / `Ctrl+P`)

После обновления Browser Source обычно обновляется сам. Если видна старая версия — ПКМ по источнику → **Refresh**.  
Если длинный текст «кто выбил» обрезается — увеличь высоту источника рулетки (540 и выше).

---

## 4. Экономика

Донаты копятся до текущего порога. Когда сумма дотягивает — запускается крутка (или несколько, если донат большой).

| Параметр | Смысл |
|----------|--------|
| Базовый порог | Стартовая цель и цель после сброса |
| Шаг роста | На сколько растёт порог после крутки |
| Снижение без донатов | Через N минут без донатов порог снижается к базе |
| Задержка перед круткой | Пауза после доната до первой крутки |
| Пауза между крутками | Пауза между крутками в одной очереди |
| Появление рулетки | Снизу вверх или сверху вниз — потом прокрут |
| Приём ВКЛ / ВЫКЛ | Временно не принимать донаты в рулетку |

После остановки ленты снизу показывается, кто выбил и какая карточка выпала. Лента при этом остаётся на месте.

---

## 5. Звук

В разделе **«Экономика»**:

- пресеты: классический / мягкий / аркадный / колокольчик;
- или свой файл (mp3 / wav / ogg);
- громкость → **«Применить звук»** / **«Прослушать»**.

---

## 6. Раскладка оверлея

1. Включи **«Режим правки»**.
2. В окне оверлея перетаскивай блоки мышью; колёсико — масштаб.
3. В панели задай ширину / высоту / масштаб → **«Сохранить раскладку»**.
4. Выключи режим правки перед эфиром.

---

## 7. Платформы донатов

В шапке справа — **бургер-меню** с названием активной платформы и статусом. Выбери Donation Alerts / DonatePay / DonateX — откроется окно подключения.

Можно подключить несколько платформ сразу: донаты со всех идут в общий прогресс.

У каждого стримера — свои ключи и токены. **Никому их не отправляй.**

### Donation Alerts

1. Создай своё приложение: [donationalerts.com/application/clients](https://www.donationalerts.com/application/clients)
2. Redirect URI укажи **ровно**: `http://127.0.0.1:3847/oauth/callback`  
   Важно: именно `127.0.0.1`, не `localhost`.
3. Вставь Client ID и API Key (secret) → **«Сохранить и подключить»** → войди во всплывающем окне приложения.
4. Статус **online** — готово. Окно подключения закроется само при успехе.

Если ошибка `invalid_client` / Client authentication failed: Client ID и API Key должны быть от **одной** OAuth-приложения; сохрани пару заново и подключи ещё раз.

### DonatePay

1. Токен: [donatepay.ru/page/api](https://donatepay.ru/page/api) (для EU — donatepay.eu)
2. Вставь токен, выбери регион `.ru` / `.eu` → **«Сохранить и подключить»**.
3. Статус **online** — готово.

### DonateX

1. Кабинет → Настройки → «API и Доступ»: [admin.donatex.gg](https://admin.donatex.gg/)
2. Вставь токен → **«Сохранить и подключить»**.
3. Статус **online** — готово.

## 8. Задания (категории и карточки)

Как в Donation Alerts:

| | |
|--|--|
| **Категория** | Группа карточек одной редкости |
| **Карточки** | Тексты через запятую, например: `Прыгнуть, Присесть, Выпить чаю` |
| **Редкость** | Обычная / Необычная / Редкая / Эпическая / Легендарная |
| **Шанс** | Считается автоматически среди включённых категорий |

По умолчанию есть «Стандартная категория».  
Иконка глаза — вкл/выкл категорию. Шестерёнка — спойлер (URL картинки). Кнопка **«Добавить категорию»** — ещё одна группа.

---

## 9. Частые вопросы

**Крутка не идёт**  
Проверь: есть включённые категории с карточками, приём включён, платформа online (или используй тест-донат / ручную крутку).

**В OBS старая версия**  
Refresh у Browser Source или перезапуск приложения.

**Нужен только тест без платформ**  
Раздел **«Тест перед стримом»**.

**Donation Alerts не подключается**  
Redirect URI: `http://127.0.0.1:3847/oauth/callback`. Client ID и API Key — пара из одного приложения OAuth. Подключай через окно внутри приложения.

**Текст «кто выбил» обрезан в OBS**  
Увеличь высоту Browser Source рулетки (ориентир 540 и выше).

---

## 10. Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+O` | Окно рулетки |
| `Ctrl+P` | Окно порога |
| `Ctrl+R` | Перезагрузить панель управления |

Меню **«Рулетка» → «Папка настроек»** — открывает папку с конфигами в профиле Windows.

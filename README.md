# Стрим-рулетка (приложение)

Десктопное приложение на Electron: админка и оверлей в отдельных окнах. Для стрима оверлей можно захватить окном в OBS или через Browser Source.

## Установщик (Windows)

Сборка Setup.exe:

```bash
cd "J:\Streams\Рулетка"
npm install
npm run dist
```

Готовый файл: `dist\StreamRoulette-Setup-1.1.0.exe`

Установщик NSIS:
- выбор папки установки
- ярлык на рабочем столе и в меню Пуск
- настройки, токены и задания хранятся в AppData пользователя (не удаляются при обновлении)

После установки открой приложение и в админке скопируй ссылки для OBS.

## Запуск из исходников

```bash
cd "J:\Streams\Рулетка"
npm install
npm start
```

Откроется админка. Окна оверлея (рулетка / порог) открывай кнопками в админке или меню **Рулетка** (`Ctrl+O` / `Ctrl+P`).

Только сервер без окна:

```bash
npm run server
```

## OBS

### Вариант A — захват окна (удобно с приложением)

1. Источники → **Захват окна**
2. Выбери окно `Оверлей рулетки` или `Оверлей порога`
3. При необходимости обрежь края

### Вариант B — Browser Source

Два источника (рекомендуется):

1. **Рулетка:** `http://127.0.0.1:3847/overlay/roulette/`
2. **Порог:** `http://127.0.0.1:3847/overlay/hud/`

Либо один общий: `http://127.0.0.1:3847/overlay/`

Размеры: рулетка ~960×360, порог ~560×420. Фон прозрачный.

Приложение должно быть запущено.

После обновления/перезапуска приложения Browser Source обычно сам перезагружается. Если в OBS видна старая версия — ПКМ по источнику → Refresh.

## Логика

| Параметр | По умолчанию | Смысл |
|----------|--------------|--------|
| Базовый порог | 100 ₽ | Старт и цель после сброса |
| Шаг | 50 ₽ | Рост порога после крутки |
| Сброс | 60 мин | Без донатов → порог снижается к базе |
| Задержка перед круткой | 5 сек | Пауза после доната до первой крутки |
| Пауза между крутками | 2500 мс | Пауза после одной крутки до следующей |
| Появление рулетки | снизу вверх | Въезд ленты перед прокруткой (или сверху вниз) |
| Накопление | да | Несколько донатов копятся до порога |

Перед эфиром: тест-донаты в админке → смотри крутку в окне оверлея / OBS.

## Платформы донатов

Можно подключить **Donation Alerts**, **DonatePay** и **DonateX** одновременно — все донаты идут в общий прогресс. В админке раздел **«Платформы донатов»**.

### Donation Alerts

1. Открой https://www.donationalerts.com/application/clients и создай приложение.
2. В **Redirect URI** укажи ровно: `http://127.0.0.1:3847/oauth/callback`
3. В админке вставь Client ID и API Key → **Сохранить и подключить**.
4. Бейдж **DA: online** — донаты идут в рулетку.

### DonatePay

1. Открой https://donatepay.ru/page/api (для EU — donatepay.eu) и скопируй **API access token**.
2. В админке → DonatePay: вставь токен, выбери регион (.ru / .eu) → **Сохранить и подключить**.
3. Бейдж **DP: online** — готово.

### DonateX

1. В кабинете https://admin.donatex.gg/ открой **Настройки → «API и Доступ»**.
2. Скопируй API-токен → в админке DonateX → **Сохранить и подключить**.
3. Бейдж **DX: online** — готово.

Токены и секреты **не кидай в чат**.

## Структура

```
electron/   — оболочка приложения (окна)
server/     — логика, API, DA / DonatePay / DonateX
public/     — UI админки и оверлея
data/       — сохранённые настройки и задания (в AppData у установщика)
```

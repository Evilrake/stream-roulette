Установщик Windows: StreamRoulette-Setup-1.2.0.exe


--------------------------------------------------------------------------------
1. УСТАНОВКА
--------------------------------------------------------------------------------

1) Запусти StreamRoulette-Setup-1.2.0.exe.
2) Выбери папку установки → Далее.
3) После установки открой «Стрим-рулетка» с рабочего стола или из меню Пуск.

Настройки, задания и токены платформ сохраняются в AppData пользователя.
При обновлении на новую версию они обычно не сбрасываются.


--------------------------------------------------------------------------------
2. БЫСТРЫЙ СТАРТ ПЕРЕД СТРИМОМ
--------------------------------------------------------------------------------

1) Запусти приложение — откроется панель управления.
2) В разделе «Задания» добавь задания (текст + вес; спойлер по желанию).
3) В «Экономика» настрой порог, шаг, тайминги → «Сохранить настройки».
4) Подключи платформы донатов (см. раздел 7).
5) Добавь источники в OBS (см. раздел 3).
6) В «Тест перед стримом» проверь кнопками +50 / +100 / «Ручная крутка».


--------------------------------------------------------------------------------
3. OBS
--------------------------------------------------------------------------------

Приложение должно быть запущено.

Рекомендуется ДВА источника Browser Source:

  Рулетка:  http://127.0.0.1:3847/overlay/roulette/
            размер ≈ 960 × 360

  Порог:    http://127.0.0.1:3847/overlay/hud/
            размер ≈ 560 × 420

Ссылки также копируются из блока «Ссылки для OBS» в админке.
Фон источника — прозрачный.

Альтернативы:
  • один общий URL: http://127.0.0.1:3847/overlay/
  • «Захват окна» → окна рулетки / порога из приложения
    (кнопки в админке или Ctrl+O / Ctrl+P)

После обновления приложения Browser Source обычно обновляется сам.
Если в OBS видна старая версия — ПКМ по источнику → Refresh.


--------------------------------------------------------------------------------
4. ЭКОНОМИКА (КАК РАБОТАЕТ)
--------------------------------------------------------------------------------

Донаты копятся до текущего порога. Когда сумма дотягивает — запускается
крутка (или несколько, если донат большой).

  Базовый порог              Стартовая цель и цель после сброса
  Шаг роста                  На сколько растёт порог после крутки
  Снижение без донатов       Через N минут без донатов порог снижается к базе
  Задержка перед круткой     Пауза после доната до первой крутки
  Пауза между крутками       Пауза между крутками в одной очереди
  Появление рулетки          Снизу вверх или сверху вниз — потом прокрут
  Приём ВКЛ / ВЫКЛ           Можно временно не принимать донаты в рулетку


--------------------------------------------------------------------------------
5. ЗВУК
--------------------------------------------------------------------------------

В разделе «Экономика»:
  • пресеты: классический / мягкий / аркадный / колокольчик;
  • или свой файл (mp3 / wav / ogg);
  • громкость → «Применить звук» / «Прослушать».


--------------------------------------------------------------------------------
6. РАСКЛАДКА ОВЕРЛЕЯ
--------------------------------------------------------------------------------

1) Включи «Режим правки».
2) В окне оверлея перетаскивай блоки мышью; колёсико — масштаб.
3) В админке задай ширину / длину / масштаб → «Сохранить раскладку».
4) Выключи режим правки перед эфиром.


--------------------------------------------------------------------------------
7. ПЛАТФОРМЫ ДОНАТОВ
--------------------------------------------------------------------------------

Можно держать несколько сразу — всё суммируется в один прогресс.
Раздел «Платформы донатов» → меню выбора платформы.

У КАЖДОГО стримера — СВОИ ключи и токены.
Аккаунты и донаты других пользователей программы с ними не смешиваются.


=== Donation Alerts ===

1) Создай СВОЁ приложение:
   https://www.donationalerts.com/application/clients

2) Redirect URI укажи РОВНО (у всех стримеров одинаковый — это нормально):
   http://127.0.0.1:3847/oauth/callback

   Важно: именно 127.0.0.1, не localhost.
   Это адрес на компьютере стримера, а не общий сервер.

3) В админке вставь Client ID и API Key приложения
   → «Сохранить и подключить»
   → войди и разреши доступ во всплывающем окне приложения.

4) Бейдж DA: online — готово.

Почему окно внутри приложения:
системный браузер иногда блокирует возврат на http://127.0.0.1,
из-за этого токен не сохраняется.


=== DonatePay ===

1) Токен: https://donatepay.ru/page/api
   (для EU — donatepay.eu)

2) Вставь токен, выбери регион .ru / .eu
   → «Сохранить и подключить».

3) Бейдж DP: online — готово.


=== DonateX ===

1) Кабинет → Настройки → «API и Доступ»:
   https://admin.donatex.gg/

2) Токен → «Сохранить и подключить».

3) Бейдж DX: online — готово.


Токены и секреты никому не отправляй.


--------------------------------------------------------------------------------
8. ЗАДАНИЯ (КАТЕГОРИИ И КАРТОЧКИ)
--------------------------------------------------------------------------------

Как в Donation Alerts:

  Категория   — группа карточек одной редкости
  Карточки    — тексты заданий через запятую в одном поле
  Редкость    — Обычная / Необычная / Редкая / Эпическая / Легендарная
  Шанс        — считается автоматически среди включённых категорий

По умолчанию есть «Стандартная категория».
Иконка глаза — вкл/выкл категорию.
Шестерёнка — спойлер (картинка на карточках).
Можно добавить несколько категорий кнопкой «Добавить категорию».


--------------------------------------------------------------------------------
9. ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------

Крутка не идёт
  Проверь: есть задания, приём включён, платформа online
  (или используй тест-донат / ручную крутку).

В OBS старая версия
  Refresh у Browser Source или перезапуск приложения.

Нужен только тест без платформ
  Кнопки тест-доната и «Ручная крутка» в админке.

Donation Alerts не подключается
  • Redirect URI: http://127.0.0.1:3847/oauth/callback
  • Client ID и API Key — от приложения OAuth (не путать с другими ключами)
  • Подключай через «Сохранить и подключить» во всплывающем окне
  • Смотри строку статуса под кнопками DA


--------------------------------------------------------------------------------
10. ГОРЯЧИЕ КЛАВИШИ
--------------------------------------------------------------------------------

  Ctrl+O   Окно рулетки
  Ctrl+P   Окно порога
  Ctrl+R   Перезагрузить админку

Меню «Рулетка» → «Папка настроек» — открывает AppData с конфигами.

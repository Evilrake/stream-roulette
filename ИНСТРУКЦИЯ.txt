================================================================================
  СТРИМ-РУЛЕТКА — ИНСТРУКЦИЯ
  Версия: 1.2.1
================================================================================

Установщик: StreamRoulette-Setup-1.2.1.exe


--------------------------------------------------------------------------------
1. УСТАНОВКА
--------------------------------------------------------------------------------

1) Запусти StreamRoulette-Setup-1.2.1.exe.
2) Выбери папку установки → Далее.
3) После установки открой «Стрим-рулетка» с рабочего стола или из меню «Пуск».

Настройки, задания и ключи платформ сохраняются в профиле Windows (AppData).
При обновлении на новую версию они обычно не сбрасываются.


--------------------------------------------------------------------------------
2. БЫСТРЫЙ СТАРТ ПЕРЕД СТРИМОМ
--------------------------------------------------------------------------------

1) Запусти приложение — откроется панель управления.
2) В «Задания» настрой категории и карточки (см. раздел 8).
3) В «Экономика» задай порог, шаг и тайминги → «Сохранить настройки».
4) Подключи платформу донатов через бургер-меню в шапке (см. раздел 7).
5) Добавь источники в OBS (см. раздел 3).
6) В «Тест перед стримом» проверь кнопками +50 / +100 / «Ручная крутка».

В шапке индикатор «WS: ok» означает, что панель связана с локальным сервером
приложения. Это не статус Donation Alerts / DonatePay / DonateX.


--------------------------------------------------------------------------------
3. OBS
--------------------------------------------------------------------------------

Приложение должно быть запущено.

Рекомендуется два источника Browser Source:

  Рулетка:  http://127.0.0.1:3847/overlay/roulette/
            размер ≈ 960 × 540

  Порог:    http://127.0.0.1:3847/overlay/hud/
            размер ≈ 560 × 420

Ссылки и кнопки предпросмотра — в блоке «Ссылки для OBS» в панели управления.
Фон источника оставь прозрачным.

Альтернативы:
  • один общий URL: http://127.0.0.1:3847/overlay/
  • «Захват окна» → окна «Оверлей — рулетка» / «Оверлей — порог»
    (кнопки «Окно рулетки» / «Окно порога» или Ctrl+O / Ctrl+P)

После обновления приложения Browser Source обычно обновляется сам.
Если в OBS видна старая версия — ПКМ по источнику → Refresh.
Если длинный текст «кто выбил» обрезается — увеличь высоту источника рулетки.


--------------------------------------------------------------------------------
4. ЭКОНОМИКА
--------------------------------------------------------------------------------

Донаты копятся до текущего порога. Когда сумма дотягивает — запускается
крутка (или несколько, если донат большой).

  Базовый порог              Стартовая цель и цель после сброса
  Шаг роста                  На сколько растёт порог после крутки
  Снижение без донатов       Через N минут без донатов порог снижается к базе
  Задержка перед круткой     Пауза после доната до первой крутки
  Пауза между крутками       Пауза между крутками в одной очереди
  Появление рулетки          Снизу вверх или сверху вниз — потом прокрут
  Приём ВКЛ / ВЫКЛ           Можно временно не принимать донаты в рулетку

После остановки ленты снизу показывается, кто выбил и какая карточка выпала.
Лента при этом остаётся на месте.


--------------------------------------------------------------------------------
5. ЗВУК
--------------------------------------------------------------------------------

В разделе «Экономика»:
  • пресеты: классический / мягкий / аркадный / колокольчик;
  • или свой файл (mp3 / wav / ogg);
  • громкость → «Применить звук» / «Прослушать».


--------------------------------------------------------------------------------
6. РАСКЛАДКА ОВЕРЛЕЯ
--------------------------------------------------------------------------------

1) Включи «Режим правки».
2) В окне оверлея перетаскивай блоки мышью; колёсико — масштаб.
3) В панели задай ширину / высоту / масштаб → «Сохранить раскладку».
4) Выключи режим правки перед эфиром.


--------------------------------------------------------------------------------
7. ПЛАТФОРМЫ ДОНАТОВ
--------------------------------------------------------------------------------

В шапке справа — бургер-меню с названием активной платформы и статусом.
Выбери Donation Alerts / DonatePay / DonateX — откроется окно подключения.

Можно подключить несколько платформ сразу: донаты со всех идут в общий прогресс.

У каждого стримера — свои ключи и токены. Никому их не отправляй.


=== Donation Alerts ===

1) Создай своё приложение:
   https://www.donationalerts.com/application/clients

2) Redirect URI укажи ровно:
   http://127.0.0.1:3847/oauth/callback

   Важно: именно 127.0.0.1, не localhost.

3) Вставь Client ID и API Key (secret) → «Сохранить и подключить»
   → войди в DA во всплывающем окне приложения.

4) Статус online — готово. Окно подключения закроется само при успехе.

Если ошибка invalid_client / Client authentication failed:
  • Client ID и API Key должны быть от одной и той же OAuth-приложения;
  • не путай их с другими ключами кабинета DA;
  • сохрани пару заново и подключи ещё раз.


=== DonatePay ===

1) Токен: https://donatepay.ru/page/api
   (для EU — donatepay.eu)

2) Вставь токен, выбери регион .ru / .eu → «Сохранить и подключить».

3) Статус online — готово.


=== DonateX ===

1) Кабинет → Настройки → «API и Доступ»:
   https://admin.donatex.gg/

2) Вставь токен → «Сохранить и подключить».

3) Статус online — готово.


--------------------------------------------------------------------------------
8. ЗАДАНИЯ (КАТЕГОРИИ И КАРТОЧКИ)
--------------------------------------------------------------------------------

Как в Donation Alerts:

  Категория   — группа карточек одной редкости
  Карточки    — тексты заданий через запятую в одном поле
                Пример: Прыгнуть, Присесть, Выпить чаю
  Редкость    — Обычная / Необычная / Редкая / Эпическая / Легендарная
  Шанс        — считается автоматически среди включённых категорий

По умолчанию есть «Стандартная категория».
Иконка глаза — включить / выключить категорию.
Шестерёнка — спойлер (URL картинки на карточках).
Кнопка «Добавить категорию» — ещё одна группа карточек.


--------------------------------------------------------------------------------
9. ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------

Крутка не идёт
  Проверь: есть включённые категории с карточками, приём включён,
  платформа online (или используй тест-донат / ручную крутку).

В OBS старая версия
  Refresh у Browser Source или перезапуск приложения.

Нужен только тест без платформ
  Раздел «Тест перед стримом».

Donation Alerts не подключается
  • Redirect URI: http://127.0.0.1:3847/oauth/callback
  • Client ID и API Key — пара из одного приложения OAuth
  • Подключай через окно внутри приложения («Сохранить и подключить»)

Текст «кто выбил» обрезан в OBS
  Увеличь высоту Browser Source рулетки (ориентир 540 и выше).


--------------------------------------------------------------------------------
10. ГОРЯЧИЕ КЛАВИШИ
--------------------------------------------------------------------------------

  Ctrl+O   Окно рулетки
  Ctrl+P   Окно порога
  Ctrl+R   Перезагрузить панель управления

Меню «Рулетка» → «Папка настроек» — открывает папку с конфигами в профиле Windows.
